# UR10 Robot Driver

> Universal Robots UR10 driver via `ur_rtde` — direct RTDE control interface.
> **File:** `app/robots/ur10.py`

---

## Connection

| Port | Use |
|---|---|
| `29999` | Dashboard — lifecycle commands and gripper `.urp` programs |
| RTDE (internal) | `ur_rtde` library handles RTDE protocol internally |

```python
robot = create_robot("UR10", ip="192.168.X.X")
# Internally opens:
rtde_control.RTDEControlInterface(ip)   # motion commands
rtde_receive.RTDEReceiveInterface(ip)   # state readback
socket → ip:29999                       # dashboard
```

---

## Protocol Design

Motion is sent directly via `ur_rtde`'s `RTDEControlInterface` — no custom URScript server, no register map. The library manages the RTDE session internally.

- **Motion:** `rtde_c.moveL(pose, vel, acc, asynchronous=True)` / `rtde_c.moveJ(q, vel, acc, asynchronous=True)`
- **Motion completion:** `rtde_c.isSteady()` polled every 50 ms
- **State:** `rtde_r.getRobotMode()`, `rtde_r.getSafetyMode()`, `rtde_r.getActualTCPPose()`, `rtde_r.getActualQ()`
- **Lifecycle:** dashboard socket commands (`brake release`, `close safety popup`, `unlock protective stop`)

---

## Init Sequence

1. `RTDEControlInterface(ip)` — connects RTDE control session
2. `RTDEReceiveInterface(ip)` — connects RTDE receive session
3. Dashboard socket → `ip:29999`, consume welcome banner
4. Read `getRobotMode()` + `getSafetyMode()`, warn if in safety stop

---

## Mode Constants (RobotBase mapping)

| Constant | Value | Meaning |
|---|---|---|
| `MODE_RUNNING` | `1` | Executing motion (UR robotMode=7 + no safety stop) |
| `MODE_ERROR` | `9` | Safety/protective stop (safetyMode ∈ {3,6,7,8,9,10,11}) |
| `MODE_ENABLED` | `0` | Idle, ready |

---

## Unit Conversions

The pipeline uses **mm + ZYX Euler degrees**. UR robots use **metres + axis-angle (Rodrigues vector)**. The driver converts transparently:

| Direction | Conversion |
|---|---|
| `move_linear(x,y,z,rx,ry,rz)` | mm→m (`/1000`), Euler deg → axis-angle rad |
| `move_joint_angles(j1..j6)` | deg→rad (`math.radians`) |
| `get_pose()` | m→mm (`*1000`), axis-angle → ZYX Euler deg |
| `get_angle()` | rad→deg (`math.degrees`) |

## Gripper Control (Dashboard `.urp` programs)

The OnRobot RG gripper cannot be reliably controlled via direct URScript calls outside the URCap context. Instead:

1. `rtde_c.stopScript()` — stops the RTDE control script so Dashboard can load a program
2. Dashboard: `load /programs/gripper_close.urp` (or `gripper_open.urp`)
3. Dashboard: `play`
4. Poll `programState` every 0.15 s until `stopped`/`idle`
5. 1.5 s mechanical settle delay
6. `rtde_c.reuploadScript()` — restores RTDE control session

Required programs on the teach pendant:
- `/programs/gripper_close.urp` — RG6 node: width=0, force=40
- `/programs/gripper_open.urp` — RG6 node: width=110, force=40
